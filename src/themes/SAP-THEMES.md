# SAP Fiori themes

`sap-horizon.css` (Morning Horizon), `sap-horizon-dark.css` (Evening Horizon), `sap-fiori-3.css` (Quartz Light) and
`sap-fiori-3-dark.css` (Quartz Dark) are generated by `scripts/generate-sap-themes.mjs` from the `css_variables.css`
files of [`@sap-theming/theming-base-content`](https://github.com/SAP/theming-base-content) 11.36.5.

## 72 font

The SAP themes set `--eui-font-family: "72", "72full", Arial, Helvetica, sans-serif`. The 72 font (Regular and Bold woff2, Latin
subset as `72` and full character set as `72full`) is bundled in `fonts/`, copied unmodified from the same package
(Apache-2.0 per its REUSE metadata, see `fonts/README.md` and `fonts/LICENSE.txt`). It is opt-in so apps that don't use the
SAP themes don't download it:

```ts
import '@enterprise-ui/react/styles.css';
import '@enterprise-ui/react/sap-fonts.css'; // @font-face for 72 / 72full, woff2 files in dist/fonts
```

Semibold, italic, light and condensed cuts are not bundled; the browser synthesizes them from Regular/Bold.

## Regenerate

```sh
npm pack @sap-theming/theming-base-content@11.36.5 && tar xzf sap-theming-theming-base-content-11.36.5.tgz
node scripts/generate-sap-themes.mjs ./package && node scripts/contrast.mjs
```

## Contrast adjustments (11.36.5)

The generator prints these when it runs. `primary` is also the text colour of secondary and tertiary buttons, so it must reach 4.5:1 on surfaces.

- sap-horizon-dark: primary `#0070f2` → `#3890f5`, primary-hover `#0064d9` → `#4890e4`; on-primary becomes dark text (`#1d232a`)
- sap-fiori-3: text-secondary `#6a6d70` → `#626467` (4.5:1 on list hover)
- sap-fiori-3-dark: primary `#1178ce` → `#559edc`, primary-hover `#1383e1` → `#479ee7`; on-primary becomes dark text (`#29313a`)
- sap-fiori-3-dark: link `#2994ee` → `#3a9def`; neutral-text `#d3d7d9` → `#e0e2e4`
