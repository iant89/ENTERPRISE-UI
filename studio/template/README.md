# Enterprise UI Studio export template

Exported Studio projects start from this folder: a Vite + React app that depends on
`@enterprise-ui/react`. Projects exported from the Studio are licensed under MIT (see `LICENSE`);
you are free to relicense your own application code.

ZIP export uses this template in milestone M3. Until then, **Download App.tsx** in the Studio
saves the page, which can be dropped into `src/App.tsx` of a copy of this template.
