# Security policy

## Supported versions

Only the latest `main` is supported. Fixes are made on `main`; older commits and builds are not patched.

## Reporting a vulnerability

Please report vulnerabilities **privately** using GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/iant89/ENTERPRISE-UI/security/advisories/new)
(repository **Security** tab → **Advisories** → **Report a vulnerability**).

Do not open a public issue, discussion or pull request for security problems. Include steps to reproduce, affected files or components, and the impact you expect. You'll get a response in the advisory thread.
